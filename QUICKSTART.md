# Quick Start Guide

## Installation

```bash
# Install the package
pip install -e .

# Or install dependencies only
pip install -r requirements.txt
```

## Getting Started

### 1. Obtain Replay Files

You need `.slp` replay files from Super Smash Bros. Melee games. These are generated by:
- **Slippi Dolphin**: Recording games played on the Dolphin emulator
- **Slippi Nintendont**: Recording games from real GameCube/Wii hardware

Place your `.slp` files in a directory, e.g., `./replays/`

### 2. Run Basic Analysis

```bash
python example_analysis.py ./replays ./results
```

This will generate:
- Phase portrait visualization
- Potential well plots
- Distance time series
- Comprehensive analysis dashboard
- Statistical summary

### 3. Interpreting Results

#### Equilibrium Distance (D_opt)
- **< 30 units**: Aggressive, in-your-face spacing
- **30-50 units**: Balanced neutral positioning
- **> 50 units**: Defensive, long-range spacing

#### Diffusion Coefficient (σ)
- **< 2.0**: Low volatility, static positioning
- **2.0-4.0**: Moderate movement, standard dash-dancing
- **> 4.0**: High volatility, aggressive movement

#### Maximum Lyapunov Exponent (λ)
- **λ > 0.5**: Highly chaotic neutral game (unpredictable)
- **0 < λ < 0.5**: Weakly chaotic (semi-predictable)
- **λ ≤ 0**: Deterministic punish state

#### Correlation Dimension (D_2)
- **< 1.5**: Repetitive, exploitable patterns
- **1.5-2.5**: Moderate complexity
- **> 2.5**: Complex, high-level mix-ups

### 4. Custom Analysis

```python
import neutralattractors as na

# Extract data
distances = na.extract_neutral_distances("./replays")

# Compute potential
langevin = na.LangevinPotential(distances)
bins, potential = langevin.compute_potential_well()

# Find equilibrium
equilibrium = langevin.find_equilibrium_distance()
print(f"Optimal spacing: {equilibrium:.2f} units")

# Classify style
style = langevin.classify_spacing_style()
print(f"Playstyle: {style}")

# Visualize
na.plot_potential_well(bins, potential, equilibrium, save_path="my_potential.png")
```

## Example Workflows

### Workflow 1: Compare Two Players

```python
import neutralattractors as na

# Player 1 replays
p1_distances = na.extract_neutral_distances("./player1_replays")
p1_langevin = na.LangevinPotential(p1_distances)
p1_eq = p1_langevin.find_equilibrium_distance()

# Player 2 replays
p2_distances = na.extract_neutral_distances("./player2_replays")
p2_langevin = na.LangevinPotential(p2_distances)
p2_eq = p2_langevin.find_equilibrium_distance()

print(f"Player 1 equilibrium: {p1_eq:.2f}")
print(f"Player 2 equilibrium: {p2_eq:.2f}")
```

### Workflow 2: Detect Bifurcations

```python
import neutralattractors as na
import numpy as np

# Extract full telemetry
p1_data, p2_data = na.extract_full_telemetry("./replays")

# Create manifold
manifold = na.RelativeManifold(p1_data, p2_data)

# Get state vectors
state_vectors = np.array([manifold.get_state_vector(i)
                         for i in range(len(p1_data))])

# Compute Lyapunov and detect bifurcations
lyapunov = na.LyapunovAnalyzer(state_vectors)
bifurcations = lyapunov.detect_bifurcation_points(window_size=60)

print(f"Found {len(bifurcations)} bifurcation points:")
for frame in bifurcations:
    print(f"  Frame {frame} ({frame/59.94:.2f}s)")
```

### Workflow 3: Multi-Modal Basin Analysis

```python
import neutralattractors as na

distances = na.extract_neutral_distances("./replays")
langevin = na.LangevinPotential(distances)
bins, potential = langevin.compute_potential_well()

# Detect multiple basins
basins = langevin.detect_multimodal_basins(prominence=0.5)

if len(basins) > 1:
    print("Multi-modal spacing detected:")
    for i, basin in enumerate(basins):
        if i == 0:
            print(f"  Offensive Basin: {basin['distance']:.2f} units")
        elif i == 1:
            print(f"  Defensive Basin: {basin['distance']:.2f} units")
        else:
            print(f"  Basin {i+1}: {basin['distance']:.2f} units")

    # Visualize
    na.plot_multimodal_basins(bins, potential, basins,
                              save_path="multimodal.png")
```

## Common Issues

### No neutral frames found
- Check that your `.slp` files contain actual gameplay
- Verify the files aren't corrupted
- Make sure both players are active (not CPU idle)

### Import errors
- Run `pip install -r requirements.txt`
- Ensure py-slippi is installed: `pip install py-slippi`

### Visualization not saving
- Create the output directory first: `mkdir results`
- Check file permissions

## Advanced Topics

### Character-Specific Analysis

Different characters have different physics. Filter replays by character:

```python
from slippi import Game

# Filter Fox replays
fox_replays = []
for filename in os.listdir("./replays"):
    if filename.endswith('.slp'):
        game = Game(os.path.join("./replays", filename))
        # Check if player uses Fox (character ID 2)
        if any(p.leader.post.character == 2 for frame in game.frames
               for p in frame.ports if p):
            fox_replays.append(filename)
```

### Stage-Specific Analysis

Different stages have different platform layouts affecting ECB dynamics:

```python
from slippi import Game

# Filter Battlefield replays (stage ID 31)
battlefield_replays = []
for filename in os.listdir("./replays"):
    if filename.endswith('.slp'):
        game = Game(os.path.join("./replays", filename))
        if game.start.stage == 31:
            battlefield_replays.append(filename)
```
